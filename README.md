# 🔍 اكشف خويك | EXPOSE YOUR FRIEND

لعبة ويب جماعية للأصدقاء وصناع المحتوى: تعرف خويك من إجابته؟ ولا بينخدع فيك؟
تعمل من المتصفح مباشرة على الجوال والكمبيوتر، بدون تحميل ولا حسابات، بالعربية (RTL) والإنجليزية.

## طريقة اللعب

1. **محقق ومطلوب:** كل جولة يتغير المحقق تلقائيًا، والنظام يختار له «الشخص المطلوب». الكل يعرف مين المطلوب.
2. **السؤال:** المحقق يكتب أي سؤال (أو يختار من الاقتراحات).
3. **الإجابات السرية:** البقية يجاوبون سرًا، إجابة وحدة لكل لاعب بدون تعديل.
4. **التحقيق:** الإجابات تظهر للمحقق بدون أسماء وبترتيب عشوائي، ويستبعدها وحدة وحدة محاولًا إبقاء إجابة المطلوب للأخير.
   إذا استبعد إجابة المطلوب **ما يدري**: لا تنبيه ولا توقف، اللعب يكمل لين تبقى بطاقة وحدة.
5. **الكشف:** عد تنازلي، ثم تنكشف كل الهويات (الأخيرة والمستبعدة) ونتيجة المحقق.

### النقاط

| الحالة | النقاط |
|---|---|
| آخر بطاقة للمطلوب (المحقق كشفه) | 🕵️ المحقق +100 |
| آخر بطاقة لغيره (المحقق انخدع) | 🥷 المطلوب +100 |
| صاحب البطاقة الأخيرة إذا ما كان المطلوب | 🎭 +50 مكافأة خداع |

كل لاعب يأخذ دوره كمحقق، والمطلوب يُختار بحيث يقل التكرار (الأقل استهدافًا أولًا، ثم من لم يستهدفه هذا المحقق قبل). في نهاية المباراة: منصة الفائزين، ألقاب **أفضل محقق** و**ملك الخداع** و**الغامض** و**كتاب مفتوح**، وسجل كل الجولات.

## المزايا

- غرف خاصة برمز من 5 أرقام (تقبل الأرقام العربية ٠-٩)، رابط مشاركة وQR، من 3 إلى 16 لاعب.
- صاحب الغرفة يلعب كأي لاعب، يبدأ اللعب، يطرد، ينقل الإدارة، يقفل الغرفة، يلغي جولة، أو ينهي المباراة.
- الإعدادات: الحد الأقصى، اللغة، مؤقت السؤال/الإجابات/كل استبعاد (مفتوح افتراضيًا)، عدد الجولات (دورة كاملة ×1-3، عدد ثابت، أو بدون حد)، اختيار المطلوب عشوائي أو يدوي، النقاط، المؤثرات الصوتية، وضع البث.
- **شاشة البث** `/watch/رمز-الغرفة` للـ OBS أو التلفزيون: عرض كبير بدون أي تحكم وبدون أي سر.
- **وضع البث:** يخفي أسماء اللاعبين وصورهم على كل الشاشات أثناء التحقيق، والمحقق وحده يبقى يشوف اسم المطلوب.
- ردود فعل بالإيموجي تطير على كل الشاشات، مؤثرات صوتية قصيرة مولّدة (بدون موسيقى خلفية)، اهتزاز على الجوال.
- إعادة الاتصال: تحديث الصفحة أو انقطاع النت يرجعك لنفس مكانك. والخادم يحفظ الغرف في `data/rooms.json` ويستعيدها بعد إعادة التشغيل.
- معالجة الغياب: نقل الإدارة إذا غاب صاحب الغرفة 45 ث، تجاهل من غاب أثناء الإجابات، إعادة اختيار المطلوب إذا غاب قبل السؤال، وإلغاء الجولة تلقائيًا إذا خرج المحقق أو ما جاوب المطلوب.

## الأمان والسرية

كل القرارات على الخادم (`server/room.ts`): الأدوار، المراحل، الخلط، النقاط، والتحقق من كل أمر.

- كل جهاز يستلم نسخته الخاصة من الحالة (`buildView`). **صاحب أي بطاقة لا يُرسل لأي جهاز قبل انتهاء العد التنازلي**، حتى المستبعدة.
- خلط البطاقات بـ `crypto.randomInt` (Fisher–Yates) ومعرّفات عشوائية جديدة لكل جولة، فلا يرتبط الترتيب بترتيب الإرسال.
- فقط المحقق يستبعد ويكشف، إجابة وحدة لكل لاعب، ولا كشف قبل بقاء بطاقة وحدة.
- تنظيف النصوص (محارف التحكم واتجاه النص)، حدود للطول، وتحديد معدل الطلبات وإنشاء الغرف.
- الأوامر القديمة (نقرة مزدوجة أو تأخير شبكة) تُرفض إذا تغيّرت المرحلة.

## التشغيل محليًا

يحتاج [Node.js](https://nodejs.org) 20.19 أو أحدث.

```bash
npm install
npm run dev
```

افتح `http://localhost:3100`. الخادم يطبع أيضًا رابط الشبكة المحلية (مثل `http://192.168.x.x:3100`) ليدخل أصحابك من جوالاتهم على نفس الواي فاي، وزر «انسخ الرابط» يستخدمه تلقائيًا.

نسخة الإنتاج محليًا:

```bash
npm run build
npm start
```

## النشر على الإنترنت

### Render (مجاني)

1. ارفع المشروع على GitHub.
2. في Render: **New → Blueprint** واختر المستودع؛ ملف `render.yaml` يجهّز كل شيء.
3. الخطة المجانية تنام بعد 15 دقيقة بدون زوار وتصحى خلال ثوانٍ مع أول زيارة.

### Docker (أي خادم)

```bash
docker build -t ekshef-khowik .
docker run -p 3100:3100 ekshef-khowik
```

> شغّل **نسخة وحدة فقط** من الخادم: الغرف في ذاكرته. يدعم WebSocket تلقائيًا (Render وFly وRailway وأي VPS).

### متغيرات البيئة (اختيارية)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3100` | منفذ الخادم |
| `HOST` | `0.0.0.0` | عنوان الاستماع |
| `PERSIST_FILE` | `data/rooms.json` | ملف حفظ الغرف، أو `off` لتعطيله |
| `MAX_PLAYERS` | `16` | سقف عدد اللاعبين في الغرفة |
| `ALLOWED_ORIGINS` | — | نطاقات مسموحة لـ CORS (مفصولة بفواصل) إذا كانت الواجهة على نطاق آخر |

## هيكل المشروع

```
shared/        الأنواع والثوابت وبنك الأسئلة (مشتركة بين الخادم والواجهة)
server/        خادم Node: room.ts (منطق اللعبة)، roomManager.ts (الغرف والحفظ)، socket.ts (Socket.IO)، index.ts
src/           الواجهة: React + TypeScript + Tailwind CSS + Motion
  phases/      شاشة لكل مرحلة (اللوبي، الإعلان، السؤال، الإجابات، التحقيق، الكشف، النهاية)
  screens/     الصفحة الرئيسية، الغرفة، شاشة البث
  lib/         الاتصال، الجلسة، الأصوات، اللغات، المؤقتات
tests/         اختبارات Vitest
scripts/       bots.ts (لاعبون افتراضيون) و e2e.ts (اختبار بمتصفح حقيقي)
```
